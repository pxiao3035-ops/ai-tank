# AI 坦克大战 · 独立部署版

这个文件夹就是完整的游戏网站：打开网址就能玩，朋友不用注册任何账号就能联机。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 游戏本体（单个网页） |
| `server.js` | 把网页发给浏览器，并提供联机用的房间通道 |
| `package.json` | 告诉托管平台用 `node server.js` 启动 |

需要 Node.js 18 或更新版本。不用安装任何依赖。

## 先在自己电脑上试

1. 安装 Node.js（nodejs.org 下载安装包，一路下一步）。
2. 在这个文件夹里打开终端，运行 `node server.js`。
3. 浏览器打开 `http://localhost:8080`。开两个窗口，就能自己和自己联机测试。

同一个 Wi-Fi 下的手机也能连：把 `localhost` 换成电脑的局域网 IP，例如 `http://192.168.1.23:8080`。

## 放到网上（两种办法，选一种）

### 办法一：托管平台（不用管服务器）

适合 Render、Railway、Fly.io、Zeabur 这类平台，流程都差不多：

1. 把这个文件夹传到一个 GitHub 仓库。
2. 在平台上新建一个 Web Service，选这个仓库。
3. 启动命令填 `node server.js`（多数平台会自动识别）。端口不用填，程序会读平台给的 `PORT`。
4. 部署完成后平台会给一个 `https://…` 网址，发给朋友即可。

注意：要选支持 WebSocket、能一直运行的服务类型。纯静态托管（GitHub Pages、Vercel 静态站点等）只能放网页，联机用不了。

### 办法二：自己的云服务器

1. 买一台最便宜的云主机（1 核 1G 足够），装好 Node.js。
2. 把这个文件夹传上去，运行 `PORT=80 node server.js`。
3. 在云厂商的防火墙 / 安全组里放行这个端口。
4. 朋友打开 `http://服务器IP` 就能玩。

想让它关掉终端后继续运行、开机自启，用 `pm2`：`npm i -g pm2 && PORT=80 pm2 start server.js && pm2 save`。

想用 https 和域名，在前面加一层 Nginx 或 Caddy 反向代理，记得把 WebSocket 一起转发（路径是 `/ws`）。服务器在中国大陆时，用域名访问需要先备案。

## 怎么联机

1. 一个人进“联机”→“创建房间”，把 6 位房间号（或者当时的网址）发给朋友。
2. 朋友打开网址，进“联机”，输入房间号，点“准备”。
3. 房主点“开始”。

## 需要知道的

- 游戏逻辑在每个人的浏览器里算，服务器只转发操作，所以很省资源，一台小主机能带很多房间。
- 房主的浏览器负责排所有人的操作：房主离开，本局结束；非房主的操作会有一点延迟，延迟大小取决于各自到服务器的网络。
- 存档（金币、解锁、进度）在各自浏览器里，换设备不会跟着走。
- 没有账号系统，所以没有排位和段位。
- 检查服务器是否活着：打开 `/healthz`，会显示 `ok` 和当前连接数。
